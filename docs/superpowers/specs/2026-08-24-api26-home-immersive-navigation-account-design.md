# API 26 首页、沉浸光感导航与华为账号设计

## 1. 背景

错题收集应用当前使用 HarmonyOS 6.1.1（API 24）工程配置，首页入口缺失，底部使用三个标准 Tabs，分别为“书本”“错题收集”“我的”。本次升级将工程迁移到 HarmonyOS 26.0.0（API 26 Beta2），新增学习仪表盘首页，将底部导航改为四个悬浮入口，并使用 ArkUI 官方沉浸光感材质。

华为账号登录采用可选模式：未登录用户继续完整使用端侧错题、书籍、复习和导入能力；登录只负责启用多用户身份与云同步。

## 2. 已确认需求

- 工程目标 SDK 升级到 API 26，使用已安装的 DevEco Studio 26.0.0.621 与 HarmonyOS 26.0.0 Beta2 SDK。
- 底部导航从左到右固定为“首页、书籍、错题、我的”。
- 导航视觉参考用户提供的白色悬浮胶囊样式，但不保留中间加号按钮。
- 首页采用学习仪表盘布局。
- 官方沉浸光感重点用于底部导航、首页核心统计卡、登录卡片和重要弹窗，不铺满全部列表项。
- 华为账号登录不是使用应用的前置条件。

## 3. 方案选择

采用自定义 `Stack + Row` 悬浮导航，而不继续依赖默认 Tabs 外观。

原因：

- 可以精确控制左右边距、底部安全区、圆角、阴影、材质和交互动画。
- 四个页面的状态可由统一索引控制，迁移现有页面时改动边界清晰。
- 官方 `ImmersiveMaterial` 可以直接应用到导航容器，而不受标准 tabBar 背景限制。

不采用的方案：

- 继续修改标准 Tabs：改动较少，但难以稳定复刻悬浮胶囊、材质边界和安全区效果。
- 全面迁移到 Navigation：扩展性更强，但对本次单层主导航属于不必要的架构改造。

## 4. 页面与组件结构

### 4.1 应用根结构

`Index` 使用 `Stack` 叠放内容区和底部导航：

1. 内容区展示当前选中的主页面。
2. 底部放置悬浮 `MainBottomNavigation`。
3. 内容区为导航高度和系统安全区预留底部空间，避免列表内容被遮挡。

主页面索引固定为：

| 索引 | 页面 | 标签 |
| --- | --- | --- |
| 0 | `HomePage` | 首页 |
| 1 | `BooksPage` | 书籍 |
| 2 | `WrongQuestionsPage` | 错题 |
| 3 | `MinePage` | 我的 |

页面切换保留各页面的滚动位置和临时状态。现有书籍、错题、我的页面不改变核心业务行为。

### 4.2 首页学习仪表盘

首页由以下区域组成：

- 顶部问候区：显示问候语、本地/云端状态和用户头像占位。
- 今日复习卡：显示真实待复习数量，提供“开始复习”入口。
- 数据概览：错题总数、已掌握数量和掌握率。
- 最近书籍：显示最近使用的书籍，并可进入书籍页。
- 最近错题：显示最近新增记录，并可进入错题页。
- 快捷操作：导入资料、开始复习。
- 空状态：没有数据时展示引导文案和导入入口，不使用虚构统计数据。

首页只读取现有端侧数据仓库。聚合统计集中在独立的首页数据服务或视图模型中，避免页面组件直接拼接多份数据库查询逻辑。

### 4.3 悬浮底部导航

- 外层为圆角胶囊容器，左右留白并贴合底部安全区。
- 使用 API 26 官方系统材质，选择适合导航背景的中等材质强度，启用阴影、交互响应和光效。
- 选中项使用主题绿色图标和文字；未选中项为深灰色。
- 图标位于文字上方。
- 点击切换时使用短时缩放、亮度和颜色过渡，不使用大幅位移动画。
- 每个入口提供可访问性文本，并保证可点击区域不小于系统推荐尺寸。

## 5. 沉浸光感接入

### 5.1 工程配置

- 将目标 SDK 与兼容 SDK 迁移到 API 26，具体字段以 API 26 新建工程模板为准。
- 在 entry 模块元数据中启用 `ohos.arkui.UIMaterial.state=enable`。
- 使用 ArkUI `ImmersiveMaterial` 和 `ImmersiveOptions` 配置材质颜色、阴影、交互及光效。

### 5.2 使用范围

材质仅应用于：

- 主底部导航容器。
- 首页今日复习卡或核心概览容器。
- 我的页面华为账号登录卡。
- 需要强调层级的重要弹窗。

普通列表行、表单输入框和大量重复小卡片继续使用常规背景，以保持内容层级清晰并控制渲染成本。系统不支持完整光效或用户关闭相关效果时，使用材质能力自身的系统适配结果，不自行伪造设备光照数据。

## 6. 华为账号与云同步

### 6.1 登录流程

1. 用户在“我的”页面点击华为账号登录按钮。
2. 客户端通过 Account Kit 获取一次性授权码。
3. 客户端把授权码发送到现有 HTTPS 服务端。
4. 服务端使用华为 Client ID 与 Client Secret 完成身份交换和用户绑定。
5. 服务端返回应用自己的短期访问令牌与刷新机制。
6. 客户端更新登录状态，并显示同步入口和最近同步结果。

Client Secret 只存在服务器环境变量中，绝不写入 ArkTS 源码、资源文件或 HAP。

### 6.2 本地优先行为

- 未登录：所有端侧功能可用，数据只保存在本地。
- 已登录但离线：本地增删改正常进行，并记录待同步变更。
- 恢复网络：用户触发或系统条件允许时进行增量同步。
- 登录失败或服务不可用：只提示登录/同步失败，不阻塞本地功能。
- 退出登录：清理会话凭据，但默认保留本机学习数据；清除本地数据必须单独确认。

## 7. 数据与状态流

- `HomePage` 从聚合服务获取只读统计快照。
- 主导航只维护当前页面索引，不持有业务数据。
- 页面之间通过明确回调切换入口，例如首页“最近书籍”跳转到书籍页。
- 登录状态由单一账户会话服务管理，`MinePage` 和首页同步状态订阅同一状态源。
- 云同步写入现有本地数据层后，由数据版本变化触发首页刷新，避免为云端数据创建第二套 UI 状态。

## 8. 错误处理

- 数据库读取失败：对应区域显示可重试错误状态，其余首页区域继续工作。
- API 26 材质配置失败或设备降级：保持内容、导航和点击行为可用。
- 华为授权取消：视为正常取消，不显示技术错误。
- 服务器登录失败：显示简短原因与重试入口，不回退或删除本地数据。
- 会话过期：尝试刷新；刷新失败后恢复未登录状态，待同步数据继续保留。

## 9. 测试与验证

- 数据聚合测试：空库、仅有错题、已掌握数据、今日复习统计。
- 导航测试：四项顺序、默认首页、重复点击、快速切换和状态保留。
- 账户测试：登录成功、取消、服务端失败、离线和退出登录。
- 安全测试：客户端产物和源码中不包含 Client Secret。
- 构建验证：使用 API 26 Beta2 工具链执行清理构建和测试。
- 设备验证：检查安全区、横竖屏适配、光效、触摸反馈、列表不被遮挡及端侧离线可用性。

## 10. 验收标准

- 启动后默认进入首页学习仪表盘。
- 底部准确显示“首页、书籍、错题、我的”四项，并可稳定切换。
- 导航外观为悬浮圆角胶囊，使用官方沉浸光感材质。
- 首页数据来自真实端侧存储，空状态正确。
- 未登录时现有端侧功能不受影响。
- 登录入口使用华为 Account Kit，敏感密钥不进入客户端。
- API 26 工具链构建通过，现有核心测试不回归。

## 11. 暂不包含

- 全量云同步冲突合并策略的业务扩展。
- 将沉浸光感应用到所有列表项。
- 中间加号按钮或第五个主导航入口。
- API 24 双版本构建产物。
